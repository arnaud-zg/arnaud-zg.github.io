---
title: vite-workspace-resolver
description: "Vite plugin that resolves workspace exports maps and deep src/ imports"
---

Vitest fails to resolve another workspace package's subpath export or src/ file.

## Install

```sh
pnpm add -D vite-workspace-resolver
```
