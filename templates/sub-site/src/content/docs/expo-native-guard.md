---
title: expo-native-guard
description: "Swaps in a visible fallback component instead of crashing"
---

Expo Go crashes on a native-only import: a Nitro module, a TurboModule or a custom Expo module.

## Install

```sh
pnpm add -D expo-native-guard
```
